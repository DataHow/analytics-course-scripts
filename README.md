
# DataHow Teaching Course Scripts

### Guide to opening notebooks in google colab.

1. Open https://colab.research.google.com/
2. You will have already open "Welcome to Colaboratory" notebook
3. Open notebook (File -> Open Notebook) in top left or "Ctrl/Cmd + O"
4. Click on Github tab in the window that just opened.
5. Enter this repo "https://github.com/DataHow/analytics-course-scripts.git" and click search.
6. Select "DataHow/analytics-course-scripts" under Repository, and keep the "main" branch.
7. Open the first notebook, "scripts/00_Process_Introduction.ipynb".
